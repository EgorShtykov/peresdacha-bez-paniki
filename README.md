# Пересдача без паники

Интерактивный учебный тренажёр по заданиям из файла **«Подготовка к пересдаче (4).docx»**.

## Что умеет сайт

- содержит 40 исходных заданий: два варианта по 20 задач;
- предлагает 40 похожих заданий с собственными ответами и разборами;
- генерирует новые числа, параметры и графики для каждого из 40 типов;
- включает уровни «База», «Пересдача» и «Усложнение»;
- засчитывает освоение типа после верных решений на всех трёх уровнях;
- проверяет ответ, а не просто показывает решение;
- даёт подсказку по методу и пошаговый разбор;
- объясняет типичную ошибку;
- строит графики квартичной параболы и кусочной функции;
- показывает прогресс отдельно по исходным, похожим и сгенерированным заданиям;
- содержит расширенную шпаргалку с формулами;
- сохраняет прогресс локально в браузере через `localStorage`;
- работает на телефоне, планшете и компьютере;
- учитывает настройку уменьшенной анимации.

## Запуск

```bash
npm install
npm run dev
```

Сайт будет доступен на `http://localhost:3000`.

## Сборка

```bash
npm run build
npm run preview
```

Готовая статическая сборка находится в `dist`.

## Публикация на GitHub Pages

Репозиторий содержит workflow `.github/workflows/deploy.yml`. При отправке изменений в `main` GitHub Actions устанавливает зависимости, собирает проект и публикует каталог `dist` на GitHub Pages.

В настройках репозитория **Settings → Pages → Build and deployment → Source** должен быть выбран **GitHub Actions**.

В `vite.config.ts` установлено `base: './'`, поэтому сборка работает и по адресу проекта `https://<имя-пользователя>.github.io/<имя-репозитория>/`.

## Структура учебных данных

- `src/data/tasks.ts` — 40 исходных заданий;
- `src/data/similarTasks.ts` — 40 похожих заданий;
- `src/data/practiceGenerators.ts` — генераторы новых вариантов всех 40 типов;
- `src/components/PracticeLab.tsx` — тренировка темы, уровни и прогресс освоения;
- `src/components/PracticeGraph.tsx` — графики сгенерированных заданий;
- `src/utils/normalizeAnswer.ts` — общая нормализация ответов;
- `src/data/cheatSheet.ts` — содержимое шпаргалки;
- `src/components/FunctionGraph.tsx` — SVG-графики исходных и похожих заданий.

## Хранение прогресса

Используются три независимых ключа:

- `retake-trainer-solved-v1` — исходные задания;
- `retake-trainer-similar-v1` — похожие задания;
- `retake-trainer-generated-v1` — сгенерированные варианты.

Для типа засчитывается каждый уровень, на котором верно решён хотя бы один вариант. Повторная проверка того же сгенерированного варианта не увеличивает прогресс.

Сервер и база данных не используются: после очистки данных браузера прогресс удалится.

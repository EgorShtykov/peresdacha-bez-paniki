# Пересдача без паники

Интерактивный тренажёр для подготовки к пересдаче по математике. Сайт помогает не просто сверять ответы, а учиться решать задания: с подсказками, пошаговыми разборами, типичными ошибками и дополнительной тренировкой.

## Возможности

- 40 исходных заданий в двух вариантах.
- 40 похожих задач для закрепления, включая дополнительные графики функций.
- Генератор новых вариантов для всех 40 типов заданий: числа, параметры и графики меняются вместе с пересчитанным решением.
- Три уровня сложности: «База», «Пересдача» и «Усложнение».
- Освоение типа засчитывается только после верных решений на всех трёх уровнях; повтор одного варианта не увеличивает прогресс.
- Проверка ответов и независимый прогресс для исходных, похожих и сгенерированных заданий.
- Подсказки, пошаговые решения и разборы типичных ошибок.
- Шпаргалка из 17 тематических разделов и 36 формул.
- Фильтрация по темам и мотивирующие уровни подготовки.
- Адаптивный интерфейс для телефона, планшета и компьютера.

Прогресс сохраняется в `localStorage` текущего браузера. Регистрация и серверная синхронизация не используются.

## Технологии

React 19, TypeScript, Vite, Tailwind CSS, Radix UI, KaTeX и Lucide React.

## Запуск локально

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

Готовая статическая сборка создаётся в каталоге `dist`.

## Структура

- `src/data/tasks.ts` — исходные задания, ответы и решения.
- `src/data/similarTasks.ts` — похожие тренировочные задания.
- `src/data/practiceGenerators.ts` — 40 детерминированных генераторов вариантов и уровни сложности.
- `src/components/PracticeLab.tsx` — режим тренировки и прогресс освоения тем.
- `src/components/FunctionGraph.tsx` и `src/components/PracticeGraph.tsx` — SVG-графики функций.
- `src/App.tsx` — интерфейс и логика тренажёра.
- `src/index.css` — стили и адаптивная вёрстка.
